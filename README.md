# Initial installation manager for my Linux Mint install.

## Overview
This is a command line interface that will install the defaults for my system, and other optional applications and systems. 
Installing something that is already on the system will result in the install not happening, unless the overwrite option is selected for that application (or all applications).

## Interface
I use whiptail to display a GUI for this program.
